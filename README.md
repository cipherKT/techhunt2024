# techhunt2024

⚠️ This repository has been archived and is read-only. No further development, issue triage, or pull requests will be accepted.

Overview
--------
techhunt2024 contains resources, challenges, and reference solutions used for the Tech Hunt 2024 event. It was created to host puzzles, problem statements, reference implementations, and any supporting assets used during the event.

Archived status
---------------
This repository has been archived by the owner. The code and materials are preserved for historical reference only. If you found this repository via a fork or clone and need to take action, please create a new repository and migrate the files you need.

Contents
--------
- docs/        — problem statements, rules, and event documentation
- challenges/  — challenge descriptions and input data
- solutions/   — reference solutions and example implementations
- scripts/     — utility scripts used during the event
- assets/      — images, test data, and other assets
